Tipos inteiros em rust: 
| Tipo              |        Bits |                Com sinal (`i`) |                    Sem sinal (`u`) |
| ----------------- | ----------: | -----------------------------: | ---------------------------------: |
| `i8` / `u8`       |           8 |                     -128 a 127 |                            0 a 255 |
| `i16` / `u16`     |          16 |               -32.768 a 32.767 |                         0 a 65.535 |
| `i32` / `u32`     |          32 | -2.147.483.648 a 2.147.483.647 |                  0 a 4.294.967.295 |
| `i64` / `u64`     |          64 | cerca de ±9,22 **quintilhões** | até cerca de 18,44 **quintilhões** |
| `i128` / `u128`   |         128 |                     gigantesco |                         gigantesco |
| `isize` / `usize` | arquitetura |         depende da arquitetura |             depende da arquitetura |

8 bits  → dezenas 2**8 
16 bits → centenas 2**16
32 bits → milhares 2**32
64 bits → milhões 2**64
i = signed (com sinal)
u = unsigned (sem sinal)

1. Ponto flutuante: f32 e f64

Rust tem dois tipos principais para números decimais:

f32 → 32 bits → cerca de 6 a 7 dígitos de precisão
f64 → 64 bits → cerca de 15 a 16 dígitos de precisão

O f64 é o padrão do Rust.

Exemplo:

fn main() {
    let numero1: f32 = 3.14;
    let numero2: f64 = 3.141592653589793;


    println!("f32: {}", numero1);
    println!("f64: {}", numero2);
}

Se você fizer:

let valor = 3.14;

Rust normalmente entende como:

let valor: f64 = 3.14;

Importante: números de ponto flutuante trabalham com aproximações.

fn main() {
    let resultado = 0.1 + 0.2;


    println!("{}", resultado);
}

Isso pode não ser representado internamente como exatamente 0.3.

6. Tratamento de erro com expect
.expect("Erro ao capturar o valor");

Algumas operações podem dar erro.

Por exemplo, a leitura do teclado pode falhar.

O expect() diz:

Se acontecer algum erro, encerre o programa e mostre esta mensagem.

Erro ao capturar o valor

Portanto:

io::stdin()
    .read_line(&mut entrada)
    .expect("Erro ao capturar o valor");

significa:

Leia o teclado, armazene em entrada e, se ocorrer um erro, mostre uma mensagem.
