ENUM EM RUST

==================================================
1. O QUE É ENUM?
==================================================

enum significa "enumeration" (enumeração).

Um enum permite criar um tipo que pode assumir UMA entre várias
possibilidades definidas.

Exemplo:

enum TipoConta {
    Corrente,
    Poupanca,
    Salario,
}

TipoConta agora é um novo tipo.

As possibilidades dentro dele são chamadas de VARIANTES:

TipoConta
    |
    |-- Corrente
    |-- Poupanca
    |-- Salario


==================================================
2. CRIANDO E USANDO UM ENUM
==================================================

Para selecionar uma variante usamos ::

Exemplo:

let conta = TipoConta::Corrente;

Outro exemplo:

enum Cargo {
    Desenvolvedor,
    Designer,
    Gerente,
    Analista,
}

let cargo = Cargo::Desenvolvedor;


==================================================
3. POR QUE USAR ENUM?
==================================================

Uma String aceita qualquer texto:

let cargo = "Desenvolvedor";

Mas também aceitaria:

let cargo = "Qualquer coisa";

Com enum, limitamos as possibilidades:

enum Cargo {
    Desenvolvedor,
    Designer,
    Gerente,
}

Cargo::Desenvolvedor  // válido
Cargo::Designer       // válido
Cargo::Gerente        // válido

Cargo::QualquerCoisa  // ERRO

Isso torna o código mais seguro porque o compilador conhece
todas as possibilidades válidas.


==================================================
4. ENUM DENTRO DE STRUCT
==================================================

Um enum pode ser utilizado como tipo de um campo de uma struct.

Exemplo:

    Gerente,
}

#[derive(Debug)]

    id: u32,
    nome: String,
    idade: u32,

Criando:

    id: 1,

    cargo: Cargo::Desenvolvedor,

==================================================

Option é um enum muito importante da biblioteca padrão do Rust.

Conceitualmente:

enum Option<T> {

Some significa que existe um valor.

None significa ausência de valor.

let nome: Option<String> =

Option<T>

PATTERN MATCHING
Pattern Matching significa analisar um valor e verificar com qual padrão ele corresponde para decidir o que executar.

A ferramenta mais conhecida para isso é:

match

Pense assim:

VALOR
  ↓
match
  ↓
Qual padrão combina com esse valor?
  ↓
Executa o código daquele padrão
1. Exemplo básico
fn main() {
    let numero = 2;

    match numero {
        1 => println!("Um"),
        2 => println!("Dois"),
        3 => println!("Três"),
        _ => println!("Outro número"),
    }
}

Resultado:

Dois

O Rust compara:

numero = 2

match numero
    |
    |-- 1 => não corresponde
    |
    |-- 2 => corresponde! ✓
    |          ↓
    |       "Dois"
    |
    |-- 3
    |
    └-- _
